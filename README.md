# Simple Car Game

A simple racing/avoidance game built with Python and Pygame.

## Features

- Move the yellow car left and right
- Avoid the red enemy cars
- Score points as enemies pass safely
- Restart the game with the space bar
- Start screen and game-over screen

## Requirements

- Python 3.9+
- Pygame

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python car_game.py
```

## Controls

- Left Arrow: move left
- Right Arrow: move right
- Space: start or restart

## Notes

This is a simple arcade-style game and can be customized by editing the values in `car_game.py`.
